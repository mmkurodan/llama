Release notes — changes since v1.590 (Play Console "What's new").
One block per language; keep each under ~500 characters when pasting per locale.

=== en-US ===
• Swagger UI: interactive API docs at /swagger, open from Settings → "Open API Docs".
• Anthropic API: GET /v1/models, document/PDF content blocks, thinking via anthropic-beta header.
• Gemini API: model listing (GET /v1beta/models), countTokens, embedContent/batch, JSON mode, thinkingBudget.
• New endpoints: /api/ps, /api/show, /api/delete, /lora-adapters; keep_alive (unload/preload/duration).
• Bundled LLM AI Server Guide profile. Connection check panel in Settings.
• LoRA adapters at runtime. Gemini generateContent/streamGenerateContent. Qwen3-VL default vision. llama.cpp b10621.
