Release notes — changes since v1.590 (Play Console "What's new").
One block per language; keep each under ~500 characters when pasting per locale.

=== en-US ===
• LoRA adapters: apply a LoRA GGUF to the base model at runtime; select, save, and manage adapters from Settings.
• Gemini API: new Google Gemini-compatible endpoints — POST /v1beta/models/{model}:generateContent and :streamGenerateContent (v1 alias included); supports multimodal input, function calling, and thinking.
• Vision, upgraded: Qwen3-VL is the new default vision model; n_ctx auto-expands for large images; automatic GPU→CPU fallback.
• Newer engine: llama.cpp b10621 (v0.3.0) / ggml 0.22 — more models, Adreno OpenCL GPU.
