无限 AI，零云端。你的手机就是服务器。

在本地私密且免费地运行强大的 LLM，配备人人可用的轻量界面。
一台 Android 设备即成为你的专属 AI 后端，可从同一网络中的 PC、平板和其他设备访问。

---

1. 概述
基于 llama.cpp 的 LLM AI Server 是面向 Android 的完全本地 LLM 服务器：私密、离线地进行文本与多模态生成。
支持 Hugging Face 模型搜索、GGUF 下载、本地模型加载，以及可选的 MTP 推测解码以加速推理。

支持的模型系列包括 Gemma‑4 / Gemma‑4 Vision、Qwen / Qwen Vision、Mistral、LLaMA、Phi、Bonsai 等。
内置 API 服务器兼容 Ollama、OpenAI、Anthropic (Claude) Messages 和 Google Gemini API，提供聊天、补全、生成、嵌入、分词/令牌计数和模型列表等端点。
随附的 WebUI 在同一端口运行：切换模型、编辑参数、查看日志并可安装为 PWA。

MCP 与函数调用支持工具增强的工作流；通过 GBNF 和 JSON Schema 支持结构化输出。
配置档案备份与恢复，便于保存和迁移设置。

2. 目标用户与支持的设备
面向希望获得私密、完全本地 LLM 环境的用户：

- 以离线使用为主的用户
- 集成本地后端的开发者
- 调优采样与性能的高级用户
- 测试推理行为的研究者
- 注重隐私的用户

性能可调：上下文大小、线程、批大小、GPU 卸载、KV 缓存量化和可选 MTP。

3. 主要功能
- 从 Hugging Face 搜索并下载 GGUF
- Qwen3‑VL 视觉模型（内置默认）并自动检测投影器（mmproj）
- 面向大图片和长提示的上下文（n_ctx）自动扩展
- GPU 初始化失败时自动 GPU→CPU 回退
- 更智能的 Hugging Face 搜索：按模型/大小/量化的指引、设备适配度评级，以及一键下载 mmproj
- 升级的 llama.cpp 引擎（b10621, v0.3.0）——支持更新模型与 Adreno OpenCL GPU
- 通过 GET /api/diagnostics 获取设备日志
- 本地加载 GGUF
- 完全离线的 LLM 服务器
- Gemma‑4 Vision 与 Qwen Vision 投影器检测
- LoRA 适配器：运行时将 LoRA GGUF 应用于基础模型；可在设置中选择、保存和管理适配器
- MTP 推测解码
- 详细参数控制（Mirostat、DRY、XTC、Min‑p、Typical‑p、惩罚项、动态温度）
- 扩展的 KV 缓存量化选项
- 改进的 nPredict 处理
- 内置 Ollama / OpenAI / Anthropic (Claude) Messages / Google Gemini 兼容 API 服务器
- Google Gemini API：/v1beta(v1)/models/{model}:generateContent 和 :streamGenerateContent — 多模态输入、函数调用、思考模式
- Claude 兼容端点 /v1/messages（含令牌计数），可直接对接 Anthropic SDK 客户端
- 嵌入 API
- 分词 API
- 自动提示词模板选择
- 流式 / 非流式输出
- 带时间戳的日志
- 增强的多语言 WebUI
- PWA 支持
- MCP 与函数调用
- GPU 负载稳定性改进
- 配置档案备份与恢复

端点 — Ollama：/api/chat、/api/generate、/api/embed(dings)、/api/tokenize、/api/tags、/api/diagnostics · OpenAI：/v1/chat/completions、/v1/completions、/v1/embeddings、/v1/responses、/v1/models · Anthropic (Claude)：/v1/messages、/v1/messages/count_tokens · Google Gemini：/v1beta(v1)/models/{model}:generateContent、:streamGenerateContent。
完整 API 文档、示例与交互式测试器：https://micklab.web.app/llama-tester-en.html

4. 快速开始
你可以通过以下任一方式立即开始使用：

A) 启动 API/WebUI → 在浏览器中打开
1. 在主界面点按“启动 API/WebUI”。
2. 点按“在浏览器中打开”以启动内置 WebUI。
3. 可直接在 WebUI 中聊天并运行模型。
   - 注意：首次使用时若模型尚未下载，WebUI 会在你发送第一条消息时下载（大模型可能较慢）。

B) 直接运行
1. 打开主界面的“直接运行”部分。
2. 输入提示词并点按“发送”，即可在应用内运行模型。
   - 若模型尚未下载，应用会在下载前提示。

C) 或先在设置中准备模型
1. 打开设置。
2. 在 Hugging Face 搜索 GGUF 模型，或输入直链 URL，或导入本地 GGUF 文件。
3. 调整参数（上下文大小、温度、惩罚项、MTP、GPU 卸载等）。
4. 点按“保存配置”，再点按“保存并关闭”以加载模型。
5. 如有需要，可创建配置档案备份以便日后恢复。
